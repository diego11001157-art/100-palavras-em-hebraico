# Hebraico Bíblico II — Jogo das 70 Palavras

Aplicativo Android offline para estudo do vocabulário de Hebraico Bíblico II.

## Gerar o APK no GitHub
1. Envie todos os arquivos deste projeto para um repositório GitHub.
2. Abra a aba **Actions**.
3. Selecione **Build APK**.
4. Clique em **Run workflow**.
5. Ao terminar, baixe o artefato **Hebraico-Biblico-II-APK**.
6. Dentro do ZIP estará `app-debug.apk`.

O aplicativo funciona offline porque o jogo está embutido em `app/src/main/assets/index.html`.
