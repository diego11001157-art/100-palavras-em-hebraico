# Alef - PWA para iPhone/iPad

Envie o conteúdo desta pasta para uma pasta `docs` na raiz do repositório GitHub.

Depois:
1. GitHub > Settings > Pages
2. Source: Deploy from a branch
3. Branch: main
4. Folder: /docs
5. Save

Abra o endereço publicado no Safari do iPhone e use:
Compartilhar > Adicionar à Tela de Início > Abrir como App da Web.
